# 공식 데이터 연결 계획

## 1. 전국 공장등록정보
한국산업단지공단 Factory On: https://www.factoryon.go.kr/
공장등록 원본을 확인하고 이용조건, 업데이트 주기, 주소 표준화, 좌표 변환을 검증한 뒤 적재합니다.
공장 등록정보는 부동산 매물 정보와 다릅니다.

## 2. 실거래가
국토교통부 공장 및 창고 등 부동산 매매 실거래가: https://www.data.go.kr/data/15126470/openapi.do
국토교통부 토지 매매 실거래가: https://www.data.go.kr/data/15126466/openapi.do

두 API는 법정동 앞 5자리 및 계약년월을 기준으로 조회하며 인증키가 필요합니다.
일부 지번은 개인정보 보호 목적으로 마스킹됩니다.
정확한 개별 공장 매칭이 불가능한 거래는 **지역 단위 통계**로만 활용합니다.
거래가와 매물 호가, 추정 시세는 절대 혼합하지 않습니다.

## 3. 건축물 정보
건축물대장·건축 인허가 공개자료를 별도 검증 후 연결합니다.
설계/시공업체별 실적 검색은 제품 범위에서 제외합니다.

## 배포 및 보안
API 인증키는 절대로 브라우저 JS나 GitHub 저장소에 넣지 않습니다.
추후 서버 측 수집 작업에서 환경변수로 주입합니다.
기본 화면의 네 공장은 가상 데이터이며 공식 자료가 아닙니다.
